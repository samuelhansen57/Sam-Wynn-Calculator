# Sam-Wynn-Calculator
This is a calculator written in C# and HTML Code, made by Wynn and Sam so that you don't have to beg Mr. Anderson for a calculator.
This will be upgraded to be even better than the Google calculator. We will also start to integrate Google Lens and ChatGPT into this for further calculation solutions (i.e. sending a picture or screenshot of the problem and it will solve it for you).
To run the calculator for now, paste the entire code into this website: https://www.programiz.com/csharp-programming/online-compiler/
When it asks you for the expression, just write the equation you want to solve and press enter.
